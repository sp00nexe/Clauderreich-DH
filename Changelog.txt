Version scheme
---------------
Our versions are <upstream version>.<our increment>:

  1.9.3.1   our first change on top of upstream 1.9.3
  1.9.3.2   our second change, and so on

One version == one commit. Bump the counter for every commit that changes
anything the game loads; leave it alone for commits that only touch docs or
tooling.

How to use this file
--------------------
1. Make the change.
2. Add an entry under your own name at the bottom, using the next version
   number and the current date (YYYY-MM-DD).
3. Commit with the message: v<version>: <one-line summary>
4. Never edit an entry that has already been committed; add a new version
   instead.

1.9.3.1 - 2026-10-21
  Added
  * Registered db/ministers/ministers_ddr.csv and db/ministers/ministers_dfr.csv
    in db/ministers.txt. DDR and DFR already had country rows, world names,
    counters, name tables, leaders (commiegermany.csv / federalgermany.csv) and
    teams; their cabinets were the only missing piece. Zero minister-ID
    conflicts against the other 213 files, and every portrait reference
    resolves. Still inert - the countries cannot be released before 1967 and
    the campaign ends 1964.
  Removed
  * db/leaders/leaders_u34.csv. The file held Italian fascist leaders tagged
    U34, but U34 is Crimea (db/revolt.txt: "U34 = { # Crimea"). All eleven men
    already exist in db/leaders/socialitaly.csv (RSI), and three of its IDs
    collided with db/leaders/libya.csv. U34's real leaders live in
    db/leaders/crimea.csv.

1.9.3.2 - 2026-10-21
  Changed
  * Replaced music/Die_Wacht_am_Rhein.mp3 with a shorter, higher-fidelity
    encode of the same track. The committed file was MPEG-2 Layer III,
    22.05 kHz, CBR 64 kbps, 4:33 (273 s), 2.1 MB. The new file is MPEG-1
    Layer III, 48 kHz, VBR 32-192 kbps (mostly 128/160), 0:45 (45 s), 745 KB -
    about a third of the size, and it loops cleanly as short lobby music.

1.9.3.3 - 2026-10-21
  Added
  * config/models.csv: 199 new Japanese model rows, covering every slot the
    tech tree can grant Japan in artillery, armoured vehicles, aircraft, ships
    and their naval fittings - e.g. Type 1 Ho-Ni, Type 89 I-Go, Shinhoto
    Chi-Ha, Type 97 45 mm AT Gun, Kuma-class, Kugisho MXY-7 Ohka.
  * config/models.csv: named the six Japanese rows that existed but were
    blank - BRIG_MODEL_JAP_1_1/1_2/1_3/1_4/1_12/1_13 (Type 41 75 mm mountain
    gun, Type 38 15 cm howitzer, Type 41 75 mm field gun, Type 90 75 mm field
    gun, Type 1 and Type 60 105 mm howitzers).
  * All 205 names are unique across the whole file; the file stays CP1252 with
    CRLF endings, the X sentinel in column L and #EOF on the last row.
